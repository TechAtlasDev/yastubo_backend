## ✨ El Futuro de los Seguros para Migrantes

Yastubo no es solo una API; es una **infraestructura modular de alta fidelidad** diseñada para orquestar la protección familiar funeraria global. Liderado por una visión Fintech, el sistema combina rigor actuarial con agilidad tecnológica para ofrecer tranquilidad a quienes más lo necesitan.

### 🚀 Capacidades Core
*   **🏦 Stripe Connect Native:** Gestión de carteras, suscripciones automatizadas y flujo de fondos transparente.
*   **📜 State Machine Mastery:** Control determinístico y legal del ciclo de vida de la póliza (Draft → Active → Cancelled).
*   **🤖 AI Integration:** Agentes inteligentes que automatizan el análisis de riesgos y el soporte operativo masivo.
*   **🔍 Auditoría Total:** Trazabilidad absoluta de cada cambio mediante nuestro motor `@audited` (quién, qué y cuándo).
*   **⚙️ Modular por Diseño:** Arquitectura basada en dominios desacoplados listos para escalar masivamente.

## 🛠️ Yastubo Dev Machine (CLI) 🚀

Centraliza todo el ciclo de desarrollo desde tu terminal. Nuestra **Terminal User Interface (TUI)** interactiva permite gestionar módulos, ejecutar tests y monitorear el sistema con un solo comando.

```bash
make cli
```

## 🧩 Arquitectura Modular (Domain-Driven)

Cada pieza de inteligencia está en su lugar para garantizar la escalabilidad y el mantenimiento continuo:

*   **🔐 Auth:** Seguridad robusta mediante JWT y control de acceso por roles (RBAC).
*   **📋 Plans:** Motor Actuarial dinámico con recargos por edad, países y versionado fluido.
*   **🖋️ Emission:** Orquestación compleja de Leads, registro de clientes y emisión de pólizas.
*   **💳 Payments:** Gestión de webhooks financieros, carteras y reconciliación de pagos.
*   **🩺 Claims:** Gestión sensible de siniestros, validación de beneficiarios y servicios.
*   **🤖 AI:** Modelos y prompts optimizados para la automatización inteligente.
