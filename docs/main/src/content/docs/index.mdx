## What is Yastubo?

Yastubo Backend is a REST API built with **FastAPI** that manages funeral insurance plans for migrants. It covers the full lifecycle: plan configuration, policy issuance, Stripe-based payments, and a self-service client portal.

## Modules

<CardGrid stagger>
	<Card title="Authentication" icon="approve-check-circle">
		User registration, JWT login, token refresh/logout, and role-based access control (ADMIN / VENDEDOR).
	</Card>
	<Card title="Plans" icon="document">
		Create, update, price-calculate, and version-control funeral insurance plans with country and age-range configurations.
	</Card>
	<Card title="Emission" icon="pen">
		Register clients, issue policies, manage policy status transitions, and download generated PDFs.
	</Card>
	<Card title="Payments" icon="star">
		Stripe one-time payment intents, subscriptions, manual payments, transactions listing, and Connect onboarding.
	</Card>
	<Card title="Audit" icon="information">
		Paginated audit log for every action performed in the system — admin access only.
	</Card>
	<Card title="Portal" icon="laptop">
		Self-service portal for clients: view policies, manage payment methods, cancel policies, and pay pending invoices.
	</Card>
</CardGrid>
