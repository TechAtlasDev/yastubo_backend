## ¿Qué es Yastubo?

El backend de **Yastubo** es una potente API REST construida con **FastAPI** diseñada para orquestar el ciclo de vida completo de seguros funerarios. Desde el cálculo actuarial de primas hasta la emisión de pólizas, gestión de siniestros e integraciones financieras con Stripe y CRM Zoho.

---

## Módulos Core

<CardGrid stagger>
	<Card title="Gestión de Emisión" icon="pen">
		Orquestación de leads, registro de clientes y emisión de pólizas mediante una robusta **Máquina de Estados**.
	</Card>
	<Card title="Motor de Planes" icon="document">
		Configuración de productos con lógica de recargos por edad, país y periodos de carencia dinámicos.
	</Card>
	<Card title="Pagos y Suscripciones" icon="star">
		Integración profunda con **Stripe** para pagos recurrentes, suscripciones y gestión de carteras.
	</Card>
	<Card title="Auditoría Total" icon="information">
		Trazabilidad de cada cambio en el sistema mediante un decorador de auditoría que registra el "antes y después".
	</Card>
	<Card title="Portal de Cliente" icon="laptop">
		Auto-servicio para asegurados: gestión de métodos de pago, descarga de documentos y consulta de estado.
	</Card>
	<Card title="Inteligencia Artificial" icon="approve-check-circle">
		Agentes inteligentes para análisis de riesgo, automatización de respuestas y soporte operativo.
	</Card>
</CardGrid>
